## R2 behavior proved

- Canonical replay sequence order is never sorted or rewritten by presentation.
- Playback at 1x and 4x renders indices `1, 2, 3, 4` in the same order; the
  measured 500 ms gaps become `0.5` and `0.125` seconds respectively.
- Enriched route facts draw an event-indexed pulse between exact sender and
  recipient vessels. Missing route facts draw no pulse.
- Denial/degradation events mark the exact evidenced vessel with monochrome
  `x`, the DRAFT fault label/code, and red ink in color tiers. Timeline fault
  ticks use the same `x`/red twin.
- The timeline is synchronized to canonical event positions. Long timelines
  compress event positions into the visible rail without reordering them.
- The viewport reserves the timeline, count, event stream, and completion
  footer before allocating map rows. Fault-bearing buses/nodes are prioritized;
  truncated map blocks carry `…` rather than silently claiming completeness.
- CI PTYs render one final synchronized frame and never sleep. Plain, non-TTY,
  and dumb-terminal paths retain the byte-identical stable plain renderer.
- 256-color, true 16-color (no `38;5` escapes), and monochrome frames strip to
  identical text. Every fault/color meaning has a glyph twin.

The existing replay tests remain green, including speed bounds, terminal
viewport use, orange work causality, buoy completion, and CLI plain behavior.
