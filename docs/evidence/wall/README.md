# FLOATI TUI wall

Status date: 2026-08-16. This directory is a deterministic visual review kit,
not a claim of live execution. `scripts/capture-wall.py` constructs fixed pure
models for idle, live, degraded, replay, Harbor Chart, install, and selftest
states, then renders standard and plain testimony against explicit light and
dark terminal palettes.

The twenty-eight SVG files are the visual wall. The paired text files are the
exact theme-independent testimony. `manifest.json` records the full matrix and
a SHA-256 digest for every SVG and text source. Regenerate with `make
wall-capture`; byte drift is reviewable evidence.

The live dogfood and three-fault replay captures are separate evidence.
Synthetic wall state exists to make completeness, contrast, density, hierarchy,
the counts-only traffic map, and the three ruled buoy moments reviewable without
pretending a staged process is live.
